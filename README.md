 AI & Machine Learning Projects Collection

This repository contains a collection of Artificial Intelligence, Machine Learning, Computer Vision, and Natural Language Processing projects developed to solve real-world problems using modern AI technologies.

Projects Included

 1. Crowd Detection
AI-powered crowd detection system that identifies and monitors people in images and videos using Computer Vision techniques.

 Features
- Real-time crowd detection
- Human counting
- Bounding box visualization
- Crowd density monitoring
- Video and image processing

 Technologies
- Python
- OpenCV
- YOLO
- NumPy

---

 2. Landmark Detection

 Features

- Image preprocessing
- Deep learning prediction
- Accuracy evaluation

 Technologies
- TensorFlow
- Keras
- CNN
- Python

 3. Language Detection
Natural Language Processing project for automatically identifying the language of a given text.

 Features

- Fast text classification
- Real-time prediction

 Technologies
- Python
- Scikit-Learn
- Pandas
- NLP

4. Sentiment Analysis
